# 棒の操作の改善 100 項目 + スマホ・タブレット対応

「棒の操作が難しい」というフィードバックを受けて、操作まわりを作り直しました。
主な変更は `StickController` (操作)、`GameInput` (マウス・キー・タッチ)、`StickFeedback` (目印)、
`CameraRig` (視点)、`WataameUI` (画面) です。

## A. 棒を直接動かす

1. ドラッグした場所に棒の先端がついてくる (指・カーソルを棒の高さの水平面に投影する直接操作)
2. 棒やわたあめの近くをつかむと、つかんだ位置のずれを保ったまま動かす (棒が飛ばない)
3. 離れた場所を押すと、棒がその場所へすっと移動する (タップで移動)
4. 画面のどこからでもドラッグできる (棒を正確にクリックしなくてよい)
5. 地平線より上を指しているなど投影できないときは、画面上の移動量で動かす
6. Shift を押している間は 1/3 の速さの精密操作 (移動・上下とも)
7. 速く動かすとしっかり追従し、止まるとなめらかになる速度依存のスムージング
8. 1 フレームの移動量に上限を設け、瞬間移動しない
9. つかんでいる間は棒が光る
10. マウスを棒に重ねると棒が光る (つかめる合図)
11. マウスを棒に重ねると「ドラッグで うごかす」のヒントを出す
12. 手で動かしたら「おまかせ」は自動で止まる (操作がぶつからない)

## B. 高さ

13. 画面にいつも出ている「たかさ」の縦スライダー
14. スライダーにボウルの「ふち」の目盛り
15. スライダーにベストな深さの緑の帯
16. スライダーのつまみを指でつまみやすい大きさにする
17. 「ボウルに いれる」ボタン 1 回で、ちょうどいい半径と深さへ入れる
18. 「もちあげる」ボタン 1 回で、ボウルの上へ持ち上げる
19. ボウルに入れるときは縁の上を通ってから下げる (壁を突き抜けない)
20. ホイール 1 ノッチの量を、環境 (Windows / ブラウザ / トラックパッド) によらず一定にする
21. ホイールを続けて回すと加速する
22. R / F に加えて PageUp / PageDown でも上下できる

## C. 当たり判定

23. ボウルの外から下げると縁の上で止まり、ヒントで「上へ動かしてから下げてね」と知らせる
24. ボウルの中から外へ大きく引くと、自動で縁を越えて持ち上がる
25. わたあめが大きくなるほど壁から離す (わたあめが壁にめり込まない)
26. わたあめが大きくなるほどヘッドから離す
27. 底に押し付けると止まる
28. 壁・ヘッド・底に当たった瞬間に「コツッ」という音
29. 当たった瞬間にスマホが軽く振動する
30. 当たった瞬間に棒が少しはね返る
31. 当たった瞬間に足元のマーカーが赤く光る

## D. 回転

32. 自動くるくるを最初から ON にする
33. くるくるの速さスライダー (ゆっくり / ふつう / はやい と表示)
34. 右まわり / 左まわりの切り替え
35. 2 本指でひねって回す (タッチ)
36. 右ドラッグで回すと、離したあとも少しだけ回り続ける (慣性)
37. Q / E は押し続けると加速する
38. 回っている間はパネルの回転マークが回る
39. 手で回した分は自動くるくるに上乗せされる
40. 回っていないときは「くるくる まわすと まるくなるよ」とヒントを出す
41. スペースキー / ダブルタップでくるくる ON/OFF。ボタンの表示も同期する

## E. 傾き

42. 傾けるボタン (◀ ▶ を押している間だけ傾く)
43. 「まっすぐ」ボタンと X キーで傾きを戻す
44. 上限に近づくほどゆっくり傾くソフトリミット
45. 傾きはカメラから見た左右・奥行きを基準にする
46. 傾きの角度を表示する

## F. おまかせ・アシスト

47. 「おまかせ」: 棒がヘッドのまわりを自動で円を描いて回る
48. おまかせの円の大きさスライダー
49. おまかせを押したとき棒がボウルの外にあれば、自動でボウルへ入れる
50. ざらめがなくなって機械が止まると、おまかせも自動で止まる
51. ベストゾーン (糸がよく付く場所) をボウルの中に緑のリングで表示する
52. ベストゾーンに入るとリングとマーカーが脈打つ
53. すいよせアシスト: 機械が動いているとき、棒をベストゾーンへやさしく引き寄せる
54. すいよせアシストを設定で ON/OFF できる
55. まきとり率 (飛んできた糸のうち棒が受け止めた割合) のメーター
56. まきとり率と位置から具体的なヒントを出す (もっと深く / ヘッドに近づけて / 少し離して など)

## G. 位置の見える化

57. 棒の先端の真下 (ボウルの底面やテーブル) にマーカーを表示する
58. マーカーから先端までのガイド線で、高さがひと目でわかる
59. マーカーとガイド線の色で状態がわかる (緑 = ベスト / オレンジ = OK / グレー = 外 / 赤 = 近すぎ)
60. ヘッドに近づきすぎると赤い警告リングを出す
61. 糸が巻きついたところがときどきキラッと光る
62. 重さの数字が増えるとポンとはねる
63. 状態表示を具体的にする (あたため何 % / のこりのざらめ何 g)

## H. カメラ

64. 視点プリセット: ななめ / まえ / うえ (ボタンと V キー)
65. 「うえ」視点なら真上から位置を合わせやすい
66. Ctrl + ホイールでズーム
67. ピンチでズーム (タッチ)
68. 2 本指ドラッグでカメラを回す (タッチ)
69. ズームの範囲を制限する
70. カメラが棒を少し追いかけ、棒が画面の外に出ない
71. 「カメラを もどす」(設定画面 / Home キー / 縦画面の「くわしく」タブ)
72. できあがり表示ではドラッグ (1 本指) でも回して見られる

## I. キーボード

73. WASD / 矢印で斜めに動かしても速さが変わらない
74. キーでの移動もカメラの向きを基準にする
75. B: ボウルに入れる / L: もちあげる
76. T: おまかせ
77. V: 視点の切り替え
78. Enter: できあがり (結果画面では「もういちど」)
79. Esc / Backspace: 結果画面から戻る
80. あそびかたに最新のキー操作を表示する

## J. 入力の堅牢さ

81. マウスとタッチの両方に対応する
82. タッチから作られる疑似マウスイベントを無視して、二重に動かない
83. 2 本指の操作が始まったら、1 本指の操作を取り消す
84. 指をすべて離すまで次の 1 本指操作を始めない (2 本指 → 1 本指で棒が飛ばない)
85. UI の上で始めたドラッグ / タッチでは棒を動かさない
86. 3D のスイッチをタップしたときは棒を動かさない
87. タップとドラッグを、画面の密度に合わせたしきい値で区別する
88. ウィンドウの外でボタンを離しても、つかみっぱなしにならない
89. アプリのフォーカスが外れたら入力をリセットする
90. 画面上の移動量で動かすときは DPI で感度を補正する

## K. 画面・案内

91. 次にやること (ざらめ → スイッチ → ボウルへ) のボタンをふち取りの点滅で案内する
92. 縦画面では、次にやることがあるタブを点滅させる
93. 縦画面ではスイッチを入れると自動で「棒」タブへ切り替わる
94. あそびかたをマウス用 / タッチ用で出し分ける
95. 棒のパネルを「基本」と「くわしく」に整理する
96. 設定画面に操作の感度スライダー
97. 設定 (感度・アシスト・回転の速さと向き・おまかせの円・視点・ヘルプ) を保存して次回も使う
98. 結果画面に、次に作るときのコツを表示する
99. 「あたらしい 棒にする」は、わたあめが付いていないときは押せない
100. ヒントの言葉を操作のしかたに合わせる (「ゆびで」/「ドラッグで」)

## スマホ・タブレット対応

| 項目 | 内容 |
| --- | --- |
| 画面レイアウト | 横長 (PC・タブレット横向き)、スマホ横向き (文字を大きく・棒の設定は「くわしく」に畳む)、縦向き (下にタブつきパネル) の 3 種類を自動で切り替え |
| タッチ操作 | 1 本指ドラッグで移動、タップで移動、2 本指ひねりで回転、ピンチでズーム、2 本指ドラッグでカメラ、ダブルタップでくるくる |
| 縦画面のカメラ | 下のパネルに隠れないよう映像を上へずらし、縦長でも機械が横に収まるように引く |
| ノッチ対応 | `Screen.safeArea` を避けて UI を配置 |
| WebGL テンプレート | `Assets/WebGLTemplates/Wataame`: 画面いっぱいに表示、ページのスクロール・ピンチ拡大・右クリックメニューを止める、読み込み中の表示 |
| 負荷の調整 | スマホでは描画解像度の上限を 1.5 倍に、わたあめのシェル数を 14 → 8、メッシュ更新を 0.06 → 0.1 秒に |
| 振動 | ぶつかったときとできあがったときに `navigator.vibrate` (WebGL) / `Handheld.Vibrate` (Android・iOS) |
